Domain advantage in two-dimensional quantum-device design with multi-modal agentic harness

Shenhao Miao, Yizhou Li, Liqiao Xia, Ruihao Liu, Dingke Wang, Pablo Jarillo-Herrero, Eli Zeldov, Jiaqi Cai · 2611.30043 · 2026-11-24 · Multimodal
Tool useMultimodalScience lab

High-quality two-dimensional quantum devices are commonly fabricated from mechanically exfoliated crystals, whose irregular shapes and placement require a lithographic layout tailored to each specimen. Drawing these layouts remains largely manual. We introduce qlaybench, a benchmark that tests whether language-model agents can turn microscope images and experimental requirements into device layouts that fit the specimen. Agents with conventional tools often construct devices when material outlines are supplied, but struggle to identify those outlines from images. Modelled on the human workflow, qlaybot, a multimodal agentic harness, connects image interpretation to the tools used to align images, draw device features and inspect the resulting layout. We evaluate each layout with checks drawn from practical design experience, asking whether it fits the specimen and connects its intended components. With greater computational effort, an agent using qlaybot passes 81.5% of the benchmark tasks, compared with 24.1% when it uses conventional tools. This domain advantage highlights the importance of connecting scientific interpretation of a specimen to geometric design and provides a route towards reducing manual effort in two-dimensional quantum-device fabrication.
